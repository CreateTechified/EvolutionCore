# EvolutionCore
Overly complicated and mildly cluttered addon for GregTechCEu Modern.

### Features
- Expands the Steam Age by adding many new paralleled multiblock machines, inspired by GT:NoLeisure & many other GT:NewHorizons addons.
- Universal circuits from ULV-MAX.
- New overly complicated recipes for simple circuits.
- That's it for now...

### Where download?
- The V8 port isn't production ready yet, but neither is GTCEuM 8.0.0...
- It'll be on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/evolutioncore/files/latest) and [GitHub](https://github.com/CreateTechified/EvolutionCore/releases/latest) once the migration is made.
